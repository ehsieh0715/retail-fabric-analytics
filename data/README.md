# Source data

## Dataset

Mexico Toy Sales from the [Maven Analytics Data Playground](https://mavenanalytics.io/data-playground/mexico-toy-sales)

The dataset represents a fictional toy-store chain in Mexico and includes daily sales transactions, products, stores, a calendar, and current inventory by store and product.

The source page identifies the dataset as Public Domain.

## Expected files

```text
calendar.csv
data_dictionary.csv
inventory.csv
products.csv
sales.csv
stores.csv
```

## Local placement

Download and extract the original files into:

```text
data/raw/maven_toys/
```

The `data/raw/` directory is excluded from Git because the complete source data can be downloaded separately.

Do not modify the original source files. Cleaning and transformation will take place in Fabric Bronze, Silver, and Gold layers.

## Source limitations

The inventory file contains current stock on hand for each store-product combination. It does not provide:

- historical snapshot dates
- replenishment events
- stock movements
- purchase orders
- supplier lead times
- recorded lost sales

Any inventory-risk metrics must be interpreted using these limitations.

## Source profile

The following results are generated by the reproducible profiling script:

```bash
python scripts/profile_source.py
```

The machine-readable output is stored in
[`reports/source_profile.json`](../reports/source_profile.json).


| File | Rows | Natural key |
|---|---:|---|
| sales.csv | 829,262 | Sale_ID |
| products.csv | 35 | Product_ID |
| stores.csv | 50 | Store_ID |
| inventory.csv | 1,593 | Store_ID + Product_ID |
| calendar.csv | 638 | Date |
| data_dictionary.csv | 19 | Table + Field |

Sales cover 1 January 2022 through 30 September 2023.

Initial profiling found:

- no blank values in the six source files
- no duplicate natural keys
- no orphan product or store references in sales
- no orphan product or store references in inventory
- no non-positive sales quantities
- no negative stock quantities
- 77 explicitly recorded zero-stock combinations
- 157 store-product combinations absent from the inventory file
- product cost and price stored as currency-formatted text
- different source date formats between sales/calendar and stores

Absent inventory combinations will not be treated as zero stock because
the source does not distinguish an unlisted product from missing data.

## Confirmed source grains

- Sales: one sale transaction per Sale_ID
- Products: one row per Product_ID
- Stores: one row per Store_ID
- Inventory: one available inventory position per Store_ID and Product_ID
- Calendar: one row per calendar date

The inventory source has no business snapshot date. An ingestion timestamp
may be added for audit purposes, but it will not be presented as the date
on which the stock was measured.
